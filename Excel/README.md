# قالب Excel للموظفين

هذا القالب جاهز لفتح الملف مباشرة في Excel.

## الحقول المتاحة
- رقم الموظف
- الاسم الأول
- اللقب
- رقم التسجيل
- رقم تعريف الوطني
- رقم ضمان الاجتماعي
- القسم
- الوحدة
- المسمى الوظيفي
- الرتبة
- تاريخ الالتحاق
- رقم الهاتف
- البريد الإلكتروني
- الحالة
- العنوان

## كيفية الاستخدام
1. افتح الملف `HR_Employees_Template.csv` مباشرة في Excel.
2. أضف موظفين جدد في الصفوف التالية.
3. استخدم فلترة البيانات من علامة Excel.
4. أضف فرز حسب القسم أو الرتبة أو الحالة.
5. يمكنك بسهولة تحويل الملف إلى جدول Excel (Table) عبر خيار Insert > Table.

## المميزات
- مناسب للعرض في Excel
- سهل التعديل والتخصيص
- يفتح مباشرة في Excel و Google Sheets
- مناسب لتجميع قاعدة بيانات الموظفين

## ملاحظة
هذا قالب Excel خفيف ومباشر، مناسب للاستخدام السريع. إذا رغبت، يمكنني لاحقاً إنشاء نسخة أكثر احترافية تشمل:
- واجهة لوحة تحكم
- أزرار بحث/إضافة/تحديث
- تقارير تلقائية
- تنسيق احترافي
