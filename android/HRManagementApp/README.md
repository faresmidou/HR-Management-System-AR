# HR Management Android App

This project is a simple Android app for managing HR employees.

## Features
- Login screen with default admin account
- Dashboard with employee stats
- Search employees
- Add new employees
- Local SQLite database

## Default login
- Username: admin
- Password: admin123

## Run in Android Studio
1. Open Android Studio.
2. Choose `Open` and select the folder `android/HRManagementApp`.
3. Let Gradle sync.
4. Run the app on an emulator or connected Android device.

## Project structure
- `app/src/main/java/com/example/hrmanagement` - Kotlin source files
- `app/src/main/res/layout` - UI layouts
- `app/src/main/res/values` - strings and theme colors
