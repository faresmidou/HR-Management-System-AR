# 📊 نظام إدارة الموارد البشرية - HR Management System

برنامج متكامل لإدارة الموظفين والمستخدمين باللغة العربية، مع واجهة احترافية وقاعدة بيانات موحدة آمنة.

---

## ✨ المميزات الرئيسية

### 🔐 **الأمان والحماية**
- ✅ واجهة دخول محمية برقم سري للمشرف
- ✅ أرقام سرية منفصلة لكل موظف
- ✅ تشفير كلمات المرور
- ✅ سجل تدقيق شامل (Audit Log)
- ✅ تتبع جميع العمليات

### 👥 **إدارة الموظفين**
- ✅ إضافة وتعديل وحذف الموظفين
- ✅ بيانات شاملة:
  - **البيانات الشخصية:**
    - الاسم الأول واللقب
    - تاريخ الميلاد والعمر
    - النوع والحالة الاجتماعية
    - الصورة الشخصية
    - البريد الإلكتروني
    - رقم الهاتف
    - العنوان

  - **بيانات التعريف:**
    - رقم تعريف الوطني
    - رقم ضمان الاجتماعي
    - رقم التسجيل

  - **بيانات العمل:**
    - رقم الموظف الفريد
    - القسم والإدارة
    - الوحدة
    - الوظيفة والمسمى الوظيفي
    - الرتبة
    - تاريخ الالتحاق
    - الحالة (نشط/معطل/مجازي)

- ✅ بحث وفلترة متقدمة
- ✅ تصدير البيانات إلى Excel و PDF

### 📋 **لوحة التحكم (Dashboard)**
- ✅ إحصائيات عامة
- ✅ عدد الموظفين الإجمالي
- ✅ عدد الموظفين النشطين
- ✅ إحصائيات حسب القسم
- ✅ إحصائيات حسب الوحدة
- ✅ الموظفون الجدد

### 📊 **التقارير والإحصائيات**
- ✅ تقرير الموظفين الشامل
- ✅ إحصائيات القسم
- ✅ تقرير الحضور والغياب
- ✅ تقرير الإجازات
- ✅ طباعة احترافية (PDF)
- ✅ تصدير إلى Excel

### 💾 **قاعدة البيانات**
- ✅ قاعدة بيانات Access موحدة (.mdb)
- ✅ جميع بيانات الموظفين في ملف واحد
- ✅ حفظ وحماية البيانات
- ✅ نسخ احتياطية تلقائية
- ✅ أداء عالي وسرعة استجابة

## 🚀 البدء السريع

### المتطلبات:
- ✅ Windows XP أو أحدث
- ✅ Microsoft Office (Excel أو Access) - اختياري
- ✅ VBScript (مثبت بشكل افتراضي في Windows)

### خطوات التثبيت:

1. **استنسخ المستودع:**
   ```bash
   git clone https://github.com/faresmidou/HR-Management-System-AR.git
   ```

2. **ادخل المجلد:**
   ```bash
   cd HR-Management-System-AR
   ```

3. **شغّل البرنامج:**
   - انقر نقراً مزدوجاً على `Main.hta`
   - أو انقر على `Start.bat`

4. **أدخل بيانات الدخول (المشرف):**
   - اسم المستخدم: `admin`
   - كلمة المرور: `admin123`

## 🔑 بيانات الدخول الافتراضية

### للمشرف (Admin):
| الحقل | القيمة |
|-------|--------|
| اسم المستخدم | `admin` |
| كلمة المرور | `admin123` |

### للموظفين:
- كل موظف يحصل على رقم سري خاص به من قبل المشرف
- المثال: `emp001`, `emp002`, إلخ

⚠️ **تنبيه مهم:** غيّر كلمات المرور الافتراضية فور التثبيت!

## 📖 دليل الاستخدام

### 1️⃣ إضافة موظف جديد (المشرف فقط)
1. سجّل الدخول برقم سرك الخاص (المشرف)
2. انقر على "إضافة موظف" من القائمة الرئيسية
3. أملأ النموذج ببيانات الموظف الكاملة:
   - البيانات الشخصية (الاسم، تاريخ الميلاد، إلخ)
   - بيانات التعريف (رقم الوطني، ضمان اجتماعي، إلخ)
   - بيانات العمل (القسم، الوحدة، الرتبة، إلخ)
4. أنشئ رقماً سرياً للموظف الجديد
5. انقر على "حفظ"

### 2️⃣ تعديل بيانات الموظف (المشرف فقط)
1. من لوحة التحكم، ابحث عن الموظف
2. انقر على "تعديل"
3. غيّر البيانات المطلوبة
4. انقر على "حفظ"

### 3️⃣ عرض بيانات الموظف
- المشرف: يرى جميع البيانات لجميع الموظفين
- الموظف: يرى بيانات نفسه فقط

### 4️⃣ إنشاء تقرير (المشرف فقط)
1. انقر على "التقارير"
2. اختر نوع التقرير (موظفين، قسم، حضور، إجازات)
3. حدد المعايير إن أردت
4. انقر على "طباعة" أو "تصدير إلى Excel"

### 5️⃣ نسخ احتياطية (المشرف فقط)
1. انقر على "الإعدادات"
2. اختر "النسخ الاحتياطية"
3. انقر على "نسخ احتياطي الآن"
